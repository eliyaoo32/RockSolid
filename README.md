# RockSolid

RockSolid is a framework for building a product with AI agents: a Python backend and the clients that call it, joined by ConnectRPC contracts. It brings the guidelines, the skills, the tooling, and the shared libraries, so autonomous agents build every product to one standard.

## Who Uses It

Teams that build a product with AI agents. A project starts as a clone of RockSolid, keeps its git history, and takes RockSolid's updates with `git merge`. It then replaces this file with its product's own README.

## Architecture and Decisions

RockSolid's principles, its architecture (business modules, infrastructure libraries, executables, and deployables, with the clients and contracts around them), and the decisions behind them are described in [`.agents/skills/rocksolid/FRAMEWORK.md`](.agents/skills/rocksolid/FRAMEWORK.md).
